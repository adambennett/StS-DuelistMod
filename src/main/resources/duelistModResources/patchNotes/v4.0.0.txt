Balance Updates
-----------------
- Added a few new cards that can appear as Nameless Tomb rewards
- Removed "Upgrade Stone" relic
- Removed "Summoning Anchor" relic
- Removed "Zombie Statue" relic
- Removed several base-game relics from the pool when playing as the Duelist
- Aqua cards now have a chance to apply Damp to their targets
- Frozen values modified to 50% more damage and 90% less damage from 200%/70%
- Slight modifications to various Millennium Symbol effects
- Millennium Coin effect now reads: "Upon pickup, gain 120 Gold for each other Millennium Item you are carrying. Gain 40 Gold whenever you pickup another Millennium Item."
- Electric Orb now also reduces your Strength
- HP Box max HP increase reduced from 200 -> 50
- Millennium Prayerbook now has a limited number of uses per combat
- Solder Token now has a limited number of uses per combat
- Added "Apex" and "Endure" effects to several existing cards
- Added "Erupt" effects to a few additional cards
- Some minor changes to various Challenge Level modifiers for levels 3, 4, 5, and 6
- Many, many card balancing changes. Too many to list :)

Bug Fixes
-----------
- Fixed a lot of game crashes
- Major overhaul to the systems that setup the card pool when you start a new run. These fixes will hopefully reduce the frequency of the bug where the card pool will be filled with cards from a different deck.
- Made some improvements to various cards that deal a dynamic amount of damage to better handle damage calculation (calculating various powers like vulnerable, weak, etc. correctly)
- Made some improvements to the various custom card-select screens to ensure that a "Cancel" button is always provided to make sure that you can't softlock the game in a card selection screen
- Improved the logic that prevents certain Duelist events from spawning under certain conditions, i.e. Egypt Village event should only appear for Warrior deck

QoL
------
- Replaced all instances of "Resummon" keyword with "Special Summon" keyword
    - No functional changes - simply a name change
- Fiend synergy tribute action that allows you to pull cards from your discard now runs as one action, i.e. tributing multiple fiends will simply allow you to move multiple cards to hand at once rather than triggering a 1-card select screen for each tribute
- Added some helper code when running the "Highlight Path" mod to try to save your highlighted map nodes when exiting and reloading the game
- Added some logic when the mod starts up to save all the tier scores from the server to your disk
    - Tier scores are now only re-fetched if it's been longer than 24 hours since you last fetched them, preventing the need to make an HTTP call every time the mod starts to fetch these scores
    - Also enables the mod to display the latest fetched tier scores when playing offline, since you now will have a copy stored locally
- Attempted to reduce the volume of the orb-channeling sound effects for custom Duelist orbs
- Clarified the percentage chances on many effects, especially in keyword descriptions
- Added some logic to reduce the text size of cards with longer names
    - Also updated various cards with artificially shortened names to be more correct now that there is more space available (for example, "A. Magnet Warrior" renamed as "Alpha the Magnet Warrior"
- Added support for dynamic text in card descriptions, so things like plurality will be handled better on-the-fly (for example, card effect that says "Draw 1 card", magic number increases and the card text automatically updates to read "Draw 2 cards" instead of "Draw 2 card")
- Improved the logic that controls the coloring of upgraded Tribute costs - these numbers should now more accurately reflect as red-colored when increased, and green-colored when decreased (thanks to the authors of BaseMod for adding some code to make this possible!)
- Improved the "save slots" system when creating your own card pool
    - Now the game will allow you to save an infinite amount of custom card pools. A new save slot will be added each time you save another one.
- Made some improvements to the character selection screen
    - Added new buttons and controls on the right side of the screen, including an "Unlock All Decks" toggle
    - Fixed the logic that runs when you switch decks so that the Millennium Puzzle effects would update properly to reflect each deck's puzzle effect
- Implemented a menu option that allows you to toggle on keyword icons, which replace various common keyword (Exhaust, Retain, etc.) text on cards with icons (Thanks to the authors of StSLib mod for making this possible!)
